# lista2-p1-POO

Repositório de todas as questões da lista 2 parte 1 da disciplina de Programação Orientada a Objetos (POO) do terceiro período da UFAM. Matéria ministrada pelo professor Alternei de Souza Brito.

## Estrutura do repositório

A estrutura dos códigos neste repositório segue o padrão da POO: tendo diretórios para `domain` e `services`, assim como um arquivo `main.py` em um diretório acima de `domain` e `services`. Isso é feito para cada questão. Também há um arquivo `.txt` que contém as respostas das perguntas em cada questão. 

A estrutura é exemplificada a seguir:

```text
nomeQuestao/
├── main.py
├── perguntas.txt
├── domain/
│   ├── classe1.py
│   └── classe2.py
└── services/
    ├── metodo1.py
    └── metodo2.py 
```

## Execução dos códigos

Para executar os códigos, baixa rodar o arquivo main.py em cada questão.

`./nomeQuestao/main.py`

É possível clonar o repositório utilizando: 

`git clone https://github.com/Rodrigo-Torres-Rodrigues/lista2-p1-POO.git`
